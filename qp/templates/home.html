How every quote is checked

Five steps, three separate assurances, never merged into one “verified”.

  1. 1

    Index in isolation

    Our fixed indexer reads the raw file inside the sandbox. Uploads are never opened by the web app.

  2. 2

    AI writes an extractor

    A Vultr Serverless Inference model writes code for this layout. It runs in gVisor, with up to two retries guided by verification feedback.

  3. 3

    Source verification

    Every value must match the cell or line it cites. Hidden instructions are flagged as prompt injection.

  4. 4

    Arithmetic reconciliation

    Quantity × price, subtotals, tax and totals are recomputed with Decimal. The AI's own maths is never used.

  5. 5

    Human confirmation

    The AI only proposes which items match. A named person confirms equivalence, with a reason, on the record.
